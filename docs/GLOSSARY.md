# Glossary

- **ARP:** resolves an IPv4 address to a link-layer address on a local network.
- **CIDR:** notation for an IP network prefix, such as `192.168.1.0/24`.
- **DNS:** distributed naming system that maps names to records such as IP addresses.
- **Encapsulation:** wrapping data with protocol headers as it moves down a stack.
- **Gateway:** router/interface used to reach networks outside the local subnet.
- **Latency:** time taken for data to travel between endpoints.
- **MTU:** maximum packet size supported by a link at a given layer.
- **NAT:** network address translation, often used between private and public networks.
- **Packet:** formatted unit of data carried by a network protocol.
- **Port:** transport-layer identifier for an application endpoint.
- **Router:** forwards packets between IP networks.
- **TCP:** reliable, ordered, connection-oriented transport protocol.
- **TLS:** cryptographic protocol for confidentiality, integrity, and authentication.
- **UDP:** connectionless transport protocol without built-in delivery guarantees.
