# Common Protocols and Conventional Ports

| Protocol | Port | Purpose |
|---|---:|---|
| SSH | TCP 22 | Secure remote administration |
| DNS | UDP/TCP 53 | Name resolution |
| DHCPv4 | UDP 67/68 | Dynamic host configuration |
| HTTP | TCP 80 | Web traffic |
| HTTPS | TCP 443 | HTTP over TLS; HTTP/3 uses QUIC/UDP 443 |
| SMTP submission | TCP 587 | Mail submission |
| IMAPS | TCP 993 | Secure mailbox access |
| NTP | UDP 123 | Time synchronization |

Ports are conventions; services may listen elsewhere.
