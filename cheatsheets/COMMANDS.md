# Network Commands

| Task | Linux/macOS | Windows |
|---|---|---|
| Interface | `ip addr` / `ifconfig` | `ipconfig /all` |
| Routes | `ip route` / `netstat -rn` | `route print` |
| DNS | `dig`, `nslookup` | `nslookup` |
| Reachability | `ping` | `ping` |
| Path | `traceroute` | `tracert` |
| Sockets | `ss`, `netstat` | `netstat -ano` |
| HTTP | `curl -i URL` | `curl.exe -i URL` |

Some commands need optional packages or elevated permissions.
