# Network Fundamentals

A network is a collection of interconnected devices exchanging data through shared protocols. A host is an endpoint; a link is a communication path; a protocol defines message formats and behavior.

**Scopes:** PAN, LAN, WLAN, WAN, and the Internet. **Topologies:** star, bus, ring, mesh, and hybrid. Modern Ethernet LANs commonly use a star around switches.

**Bandwidth** is capacity; **throughput** is achieved data rate; **latency** is delay; **jitter** is variation in delay. A high-bandwidth connection can still feel slow when latency or packet loss is high.

Checkpoint: distinguish Wi-Fi signal strength, bandwidth, throughput, latency, and jitter.
