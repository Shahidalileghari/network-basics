# Network Devices

- **Switch:** forwards Ethernet frames within a LAN using MAC learning.
- **Router:** forwards IP packets between networks using a routing table.
- **Access point:** connects wireless clients to a LAN.
- **Firewall:** applies traffic policy, often using addresses, ports, state, and application data.
- **Load balancer:** distributes requests across service instances.
- **Modem/ONT:** terminates an ISP access technology.

A home router may combine routing, switching, Wi-Fi, firewall, and NAT functions.
