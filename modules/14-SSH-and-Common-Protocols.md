# SSH and Common Protocols

SSH provides encrypted remote login and secure tunneling. Prefer key-based authentication, protect private keys with passphrases, and verify recovery access before disabling password login.

Other protocols: SFTP (file transfer over SSH), SMTP (email transfer/submission), IMAP (mailbox access), NTP (time synchronization), SNMP (network monitoring), FTP (legacy unencrypted transfer).

Use secure alternatives and current configurations. Do not expose administrative services unnecessarily.
