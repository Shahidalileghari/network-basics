# Modern Protocols and Performance

HTTP/2 supports multiplexed streams and header compression. HTTP/3 maps HTTP semantics over QUIC, which uses UDP and integrates TLS 1.3. QUIC can improve connection setup and avoid TCP-level head-of-line blocking between independent streams.

CDNs reduce latency and origin load for cacheable content. Load balancers distribute traffic. Performance dimensions include latency, throughput, packet loss, jitter, congestion, connection setup time, and server processing time.
