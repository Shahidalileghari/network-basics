# Wireshark and Packet Analysis

Capture only traffic you are authorized to inspect. Start with traffic generated by your own browser or localhost service. Identify endpoints, ports, DNS lookups, TCP behavior, TLS handshakes, timing, and retransmissions.

Useful display filters: `dns`, `tcp`, `tcp.port == 443`, `ip.addr == 127.0.0.1`, `icmp`.

Encrypted HTTPS payloads are not normally readable from a passive capture, but metadata such as endpoints and timing remains observable.
