# Ethernet and Wi-Fi

Ethernet and Wi-Fi provide local link communication. Ethernet uses frames and MAC addresses; Wi-Fi uses 802.11 radio mechanisms, association, authentication, and shared-medium access.

A MAC address identifies an interface at the link layer; an IP address supports logical addressing across routed networks. MAC addressing is local-link scoped and is not a replacement for IP.

Use WPA2-AES or WPA3 where supported, strong unique passphrases, updated firmware, and guest isolation. Avoid obsolete WEP.
