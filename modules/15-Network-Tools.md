# Essential Network Tools

| Tool | Purpose |
|---|---|
| `ping` | ICMP reachability and timing |
| `traceroute` / `tracert` | Path/hop diagnostics |
| `ip` / `ipconfig` | Interface and route configuration |
| `ss` / `netstat` | Socket/listener inspection |
| `nslookup` / `dig` | DNS queries |
| `curl` | HTTP/API inspection |
| `tcpdump` | Command-line packet capture |
| Wireshark | Visual packet analysis |

Examples: `curl -i https://example.com`, `nslookup example.com`, `ip addr`, `ip route`, `ss -tulpn`, `ipconfig /all`, `route print`. Availability and flags vary by OS.
