# Network Security Fundamentals

Principles: least privilege, segmentation, defense in depth, secure administration, patching, monitoring, and encryption.

Defensive threat concepts include eavesdropping, spoofing, poisoning, denial of service, exposed services, weak credentials, misconfigured firewall rules, and lateral movement.

A firewall does not replace application authentication, authorization, input validation, or secure coding. Use MFA, restrict management interfaces, rotate secrets, and monitor traffic.
